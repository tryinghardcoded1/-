# Legit ID Checker (Philippines)

This repository contains a modular starter architecture for a Next.js 16 + Firebase anti-scam platform:

- Public verification API with blacklist-first checks and Gemini 3.1 analysis.
- User authentication component with profile document bootstrap.
- Admin-only dashboard flow to approve user reports into the global blacklist.
- Firestore security rules with strict role-based access.

See `docs/legit-id-checker-architecture.md` for the full architecture notes.
